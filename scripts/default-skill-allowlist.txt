# Canonical managed skill portfolio.
#
# This is the only source of truth for skills managed by scripts/update.sh.
# External sources must list explicit skills; do not use broad `all` installs.
#
# Format:
# root-skill <default|routed|on-demand> <skill>
# external-skill <default|routed|on-demand> <all|claude-code|codex> <label> <repo> <skill>
# gstack-skill <default|routed|on-demand> <gstack-skill>
# gsd-skill <default|routed|on-demand> <gsd-skill>
#
# Default and routed skills are installed by scripts/update.sh. On-demand
# skills remain registered but install only when named in the comma-separated
# INTUITIVE_FLOW_ON_DEMAND_SKILLS environment variable.
